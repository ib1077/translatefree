# 智頭線 ダイヤ図

元資料 `ダイヤdata.xlsx` の①を使った65列車のダイヤ図です。元Excelは書き換えません。資料の適用日は確定していません。

## 開き方

手軽に見る場合は別添 `chizu-diagram.html` を開いてください。この1ファイルだけで通信なしに動きます。

PWA版はこのフォルダー全体をHTTPSの静的サイトとして配置し、`index.html` を開きます。タイトルの「MENU → 操作・データについて」に「オフライン用の保存が完了しました」と出た後は通信なしで再表示できます。端末のブラウザーからホーム画面への追加／アプリのインストールを行います。インストール操作の名前はブラウザーによって異なります。

PCで試す場合、Python 3がある環境ならこのフォルダーで `python -m http.server 8000 --bind 127.0.0.1` を実行し、ブラウザーで `http://localhost:8000/` を開きます。終了はターミナルで Ctrl+C。`py` が使える環境では `py -3 -m http.server 8000 --bind 127.0.0.1` でも起動できます。

スマホへPWAとして入れるにはHTTPSで開いてください。PCのローカルアドレスをスマホに入力するだけではPWAのオフライン保存はできません。単独HTML版にはPWAインストール機能はありません。

## 表示

- タイトルは `ver.0.0 / ダイヤ / 2026.03 / 指で移動、拡大できます` とMENUだけ。年月はUI相談で指定された表示であり、元Excelから検証した適用日ではありません。
- 「ダイヤ」を押すと全日表示。スマホは横画面を基本とし、縦持ちでも本体を90度回転表示します。実際に端末を横にすると通常表示へ戻ります。
- 1本指で左右移動、2本指で時間軸を連続拡大・縮小。素早いフリックは慣性で移動。ドラッグ・ピンチ後の誤タップを抑制します。
- 右側は全日・移動・列車・戻る。「移動」を押したときだけ時間スライダー、全日／12時間／6時間／3時間、＋／−を表示します。
- PCはドラッグ・ホイールで移動、Ctrl＋ホイールで拡大・縮小。図にフォーカスすると矢印キーで移動、＋／−で拡縮、Homeで全日表示が可能です。
- 背景は10分または2分線のみ。2分が8画面ピクセル以上になると2分線へ自動切替。2分表示では10分線を少し強く、途中の2分線を薄く表示します。5分目盛はありません。
- 駅は上郡が上、智頭が下。元グラフの反転した距離軸と同じ向きです。
- 列車の線または番号を選ぶと、右のパネルで秒までの着発時刻を表示します。元セル・元数値はJSONに保持しています。
- 同じ距離の着発点を横に結びます。空白は数値の0に変換せず、前後の実在点を結びます。
- 各表示対象列車のラベルは1個。全日表示が混雑する場合は3時間表示で確認します。
- 普通列車は上り赤・下り青、はくとは水色、いなばは黄色。Excelの系列色をそのまま引き継ぐ方式ではありません。

## データ差し替え

`diagram-data.json` が描画用データ、`diagram-core.js` が検証・時刻・配色、`diagram-view.js` が描画、`pan-zoom.js` が指操作、`app.js` がタイトル・MENUなど画面の切替、`styles.css` が見た目です。列車の配列を読み、系列を自動生成します。1本ずつグラフ登録する作業はありません。路線図appとの将来の統合に向けた呼出方法は `INTEGRATION.md` に記載しました。

同じ構造の新しい1シート版Excelから取り込む場合はPython 3で次を順に実行します。外部ライブラリは不要です。

```text
python tools/extract_excel.py "新しいダイヤdata.xlsx"
python tools/build.py
```

変換は①の見出し、列車番号のある列、駅・着発の行、距離列を検出します。列車の追加・削除は自動で反映され、既存グラフに登録されているかどうかには依存しません。構造が一致しない、駅距離が矛盾する、時刻が逆転する場合は停止して理由を表示します。日を跨ぐ場合は翌日を含むExcel数値を明示してください。勝手に24時間を足す補正はしません。

この元資料では51D～66Dをはくと、71D～82Dをいなばとして扱います。これは明示した分類ルールであり、色からの推定ではありません。列車番号の体系が変わる際は `extract_excel.py` の分類ルールを見直すか、JSONの `service` を指定します（`ordinary`, `hakuto`, `inaba`, `other`）。`other` は細い黒線です。新しい列車体系を無条件に特急と推定するものではありません。

①の時刻と距離を変更した後、`build.py` は `data.js`、PWAの `index.html`、内容のハッシュを付けた `sw.js`、親フォルダーの単独HTMLをまとめて生成します。PWAを更新する場合はフォルダー全体を同時に差し替えてください。次にオンラインで開くと新しい一式を保存します。`diagram-data.json` だけをサーバー上で変更しても、同梱表示は変わりません。

また、タイトルの「MENU → DATA管理 → データを開く」からJSONを読み込むこともできます。端末内に保存し、通信なしでも利用します。手動で読み込んだデータはアプリ更新より優先されます。「同梱データへ戻す」で解除できます。「データを保存」は表示中のJSONを端末に保存します。読込データの表示年月は任意の `edition` フィールドを使い、未指定なら「読込DATA」と表示します。

## 印刷

タイトルの「MENU → 印刷プレビュー」でA4横向きの全日ダイヤを上下2枚表示し、「印刷する」でブラウザーの印刷画面を開きます。上下は同じ5～23時の全日図で、午前・午後への時間分割ではありません。画面のズーム・列車選択・上下フィルターから独立し、同じ元データの全65列車を印刷します。背景は10分線です。中央の線は切り分け・折り位置の目安です。印刷時はブラウザー側のヘッダー／フッターをオフにすると用紙に収まりやすくなります。

元資料で `CN30` の駅名が「上郡」、同じ行の時刻表側 `AX30` は「智頭」ですが、距離数値 `CO30=56.05` はグラフに整合しています。駅名は①の時刻表側を使用します。`B20` の着発表記は空欄のまま保存し、数値は改変しません。

## 検証

65列車・1,259時刻点を元セルと照合。元Excelの67系列（列車65＋補助2）のX/Yキャッシュと参照セルに相違なし。15秒単位の値を秒に丸める誤差は0.01秒未満。元ExcelのSHA-256は解析前後で一致。

Edgeのブラウザー検証で、単独HTMLのオフライン表示、PWAの通信遮断後の再読込、上下フィルター、65ラベル、列車選択、秒表示、JSONの読み込みと再表示、320pxの横はみ出しを確認。今回のUIではタイトルからの起動、連続ドラッグ、Ctrl＋ホイール、2本指ピンチ、縦持ち回転表示でのピンチ・ドラッグ、10分／2分切替、上下各65列車の印刷生成を確認しました。デスクトップ・844×390横画面・390×844縦持ち回転表示を画像で確認。実機スマホでの手触りとインストールは未確認です。

本アプリは元Excelの保存データの再描画です。実際のExcel画面の再計算・表示結果を開いて照合したものではありません。詳しくは別添の解析レポートを参照してください。
